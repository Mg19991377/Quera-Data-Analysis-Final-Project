# 📊 Data Analytics Capstone Project (Quera)

## 📌 درباره پروژه (Project Overview)
این پروژه یک تحلیل جامع ۵ مرحله‌ای بر روی داده‌های کسب‌وکار است که با هدف ارزیابی بازار هدف، بخش‌بندی مشتریان، سنجش نرخ بازگشت (Retention) و ارائه راهکارهای عملی برای افزایش درآمد طراحی شده است.

---

## 🏗️ ساختار پروژه (Project Structure)

```text
📁 Quera-Data-Analysis-Capstone/
 ├── 📄 README.md
 ├── 📁 1_preprocessing/         # پیش‌پردازش، تمیزکاری و آماده‌سازی داده‌ها
 ├── 📁 2_exploration/           # تحلیل اکتشافی داده‌ها و ارزیابی شاخص‌های مالی
 ├── 📁 3_market_study/          # تحلیل و مطالعه بازارهای هدف و بررسی مناطق جغرافیایی
 ├── 📁 4_rfm/                   # ارزش‌گذاری و بخش‌بندی مشتریان به ۷ گروه رفتاری
 └── 📁 5_retention_rate/        # تحلیل ماندگاری مشتریان و محاسبه نرخ بازگشت (Cohort)

یافته‌ها و دستاوردهای کلیدی (Key Findings)
فاز ۱ | پیش‌پردازش داده‌ها (Data Preprocessing):
پاک‌سازی جامع داده‌های خام، مدیریت مقادیر گم‌شده (Null) و تکراری، اصلاح تیپ داده‌ها و آماده‌سازی ساختار داده‌ای استاندارد برای تحلیل‌های مالی و رفتاری.

فاز ۲ | تحلیل اکتشافی و ساختار مالی (Exploratory Data Analysis):
دستیابی به دید شهودی از شاخص‌های کلیدی مالی شرکت، مشخص‌کردن حجم کل فروش، میانگین ارزش هر سفارش و شناسایی الگوی زمانی خریدهای کاربران.

فاز ۳ | تحلیل و مطالعه بازارهای هدف (Target Market Analysis):
ارزیابی عملکرد جغرافیایی فروش؛ شناسایی کشورها و مناطقی که علی‌رغم حجم بالای مشتریان، فروش پایینی دارند جهت اصلاح استراتژی‌های عرضه و بازاریابی منطقه‌ای.

فاز ۴ | ارزش‌گذاری و بخش‌بندی مشتریان (RFM Segmentation):
دسته‌بندی دقیق مشتریان به ۷ گروه رفتاری بر اساس ۳ معیار تازگی (Recency)، فراوانی (Frequency) و ارزش مالی (Monetary) برای تدوین کمپین‌های هدفمند.

فاز ۵ | تحلیل ماندگاری مشتریان (Customer Retention & Cohort Analysis):
رسم ماتریس Cohort و تحلیل رفتار خریدهای مجدد؛ محاسبه نرخ بازگشت (Retention Rate) مشتریان در ماه‌های متوالی پس از اولین خرید.

ابزارها و کتابخانه‌های استفاده‌شده (Tech Stack)
Python 3.x

Pandas (پیش‌پردازش، تمیزکاری و دستکاری داده‌ها)

NumPy (محاسبات عددی و آرایه‌ها)

Matplotlib & Seaborn (تصویری‌سازی داده‌ها و رسم نمودارهای تحلیلی)
